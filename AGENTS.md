# Paolo Sotelo portfolio instructions

- This repository is the public source for Paolo's personal portfolio.
- Treat all project content as private by default. A project must set `publish: true` only after its copy, claims, links, and media are reviewed for public release.
- Never add client records, credentials, account data, private workspace paths, legal or financial matters, unpublished reports, or real form submissions.
- Interactive demos use synthetic browser-local state only. They must offer Reset and must never send, save, upload, pay, message, or change an external system.
- Keep `main` production-ready. Vercel preview deployments belong to feature branches; production deploys from approved `main` only.
- Run `npm run check` before handoff. Run `npm run test:e2e` when a Chromium runtime is available.
- Remote repository creation, pushes, Vercel connections, deployments, domains, and environment changes require the workspace confirmation workflow.
